使用说明

本应用仅支持典型的魔法数据包网络唤醒。
应用会在 Wi-Fi 网络发生变化时自动刷新广播地址，当自动计算的广播地址出现异常，可以点击主界面的刷新按钮手动刷新广播地址。
广播地址根据当前设备的 Wi-Fi IPv4 地址和子网掩码于本地计算。

目标地址判断逻辑

  • 当没有手动指定发送地址时，应用会默认将数据包发送至本地 IPv4 广播地址。
  • 发送地址设定为 IPv4 或 IPv6 时，应用会将数据包发送至指定地址。
  • 发送地址设定为域名时，应用会先尝试使用系统 DNS 解析域名，然后将数据包发送至解析到的地址。

关于地址和端口设置

  • 如果只设定了端口而没有设定地址，应用会忽略端口设置。
  • 手动设定 IPv4 地址时，请确保所处网络环境配置了正确的静态 ARP 绑定。
  • 手动设定 IPv6 地址时，请确保设备拥有 IPv6 地址，并且所处网络环境支持 IPv6 唤醒。
  • 手动设定域名时，请确保配置了正确的 DNS 解析，并配置正确的网络环境
    • 应用不会判断域名是否合法，请确保输入了正确的域名。
    • 如果域名无法解析，数据包最终会被发送到广播地址。

User Guide

This app only supports standard Magic Packet network wake-up.
The app automatically refreshes the broadcast address when the Wi-Fi network changes. If the automatically calculated broadcast address is abnormal, you can manually refresh it by tapping the refresh button on the main screen.
The broadcast address is calculated locally based on the current device's Wi-Fi IPv4 address and subnet mask.

Target Address Resolution Logic

  • When no target address is manually specified, the app will send the packet to the local IPv4 broadcast address by default.
  • If the target address is set to an IPv4 or IPv6 address, the app will send the packet to that specific address.
  • If the target address is set to a domain name, the app will first resolve it using the system DNS, then send the packet to the resolved address.

About Address and Port Settings

  • If a port is set but without an address, the app will ignore the port setting.
  • When manually setting an IPv4 address, please ensure that the network environment has the correct static ARP binding configured.
  • When manually setting an IPv6 address, please ensure that the device has an IPv6 address and the network environment supports IPv6 wake-up.
  • When manually setting a domain name, please ensure that the correct DNS record is configured and the network environment is properly set up.
    • The app does not validate the domain name; please ensure you have entered a correct one.
    • If the domain name cannot be resolved, the packet will eventually be sent to the broadcast address.
